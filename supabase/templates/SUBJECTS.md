# Supabase email templates

Supabase → Authentication → Email Templates. For each template, set the subject and paste the full HTML file into the message body.

| Supabase template | File | Subject |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Welcome to NyumbaPay — please confirm your email |
| Magic Link | `magic-link.html` | Your NyumbaPay sign-in link |
| Reset Password | `reset-password.html` | Reset your NyumbaPay password |
| Invite user | `invite-user.html` | You’ve been invited to join NyumbaPay |
| Change Email Address | `change-email.html` | Confirm your new NyumbaPay email address |
| Reauthentication | `reauthentication.html` | Your NyumbaPay verification code |
